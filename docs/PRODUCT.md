## Platform

web

## Stack

Plain static HTML, CSS and progressive JavaScript, as requested. Python and Jinja render curated local content into static files; the published site needs no runtime.

## Product Purpose

Redesign https://tular.si/ as a beautiful, simple, minimal website. Preserve all reachable source text, imagery, languages, navigation sections and linked articles. Add verified references to research and media.

## Users

Confirmed by the user: a quiet, photography-led site for curious visitors, with the current structure and full research/archive content preserved. Both Slovenian and English are required.

## Capabilities and Constraints

Seven original main sections: Home, Proteus, Conservation, Research, Tular, Media and Contact. Preserve historic material without making dated project statements sound new. Store local assets and source provenance. Do not invent scientific findings, visitor bookings or contact forms with no delivery service.

## Brand Commitments

Tular Cave Laboratory; original photographs and image credits. Beautiful, simple, minimalistic design requested by the user.

## Evidence on Hand

Original tular.si material is preserved in curated content files, with provenance and validation evidence in reports/. The original import backup is stored outside the project; see README.md for its location. Verified external research and media references are recorded in content/references.json.

## Confirmed revision requirements

The user rejected similarity to https://lter.zrc-sazu.si/ and https://izrk.github.io/mks/. The revised design uses deep teal, pale stone and photography, with a red SOS banner and a sans-serif identity. Google Fonts must be linked remotely. The rescue banner must be prominent. Import scripts and directory clutter must be cleaned up; Git and a suitable ignore file are required. Actual content, links and research readability must be audited. All code, including generated HTML and CSS, must remain human-readable and unminified.
